# 반배정 도우미

4·5학년 반과 이름·성별·태그를 넣으면 6학년 반 편성을 고르게 짜 주는 도구입니다.
파일 하나(`index.html`)로 동작하는 웹앱이며, GitHub Pages에서 열립니다.

## 화면은 1→2→3→4 단계입니다

위쪽 길잡이(① 명단 올리기 · ② 반·조건 정하기 · ③ 배정하고 손보기 · ④ 엑셀로 받기)가
지금 어느 단계인지 보여 주고, 오른쪽 배지는 `실제 명단 108명` / `연습용 가상 명단 108명`처럼
지금 다루는 명단이 무엇인지 알려 줍니다.

1. 주소를 열면 **암호 입력 화면**만 보입니다. 암호가 맞고 서버에 연결되면 그때 서버에 저장된 최신 내용을 불러오며 화면이 열립니다.
2. **① 명단 올리기** — `명단 파일 올리기(.xlsx·CSV)`·`엑셀에서 붙여넣기`·`빈 양식 내려받기`로 명단을 넣습니다.
   명단 표에는 **번호(출석번호)** 칸이 있어 파일·붙여넣기의 `번호`·`출석번호`·`학번` 열을 그대로 읽습니다.
   연습은 `연습용 명단으로 해보기`(가상 108명)로 먼저 해 볼 수 있습니다.
3. **② 반·조건 정하기** — `새 반 구성`에서 반 개수와 목표 인원을 맞추고 `학생 수에 맞춰 목표 인원 채우기`를 누릅니다.
   새 반 이름은 기본이 **가반·나반·다반·라반·마반·바반**이고(반을 늘리면 사반·아반·자반·차반), 표에서 직접 고쳐도 됩니다.
   `통합학급` 체크는 특수학생을 그 반에만 두거나 목표 인원을 몇 명 적게 잡을 때 씁니다.
   `태그와 힘든 점수(★)`(기본 태그: 특수·학습·생활), `같이 두면 안 되는 학생(분리 그룹)`, 필요하면 `같은 반이 되면 좋은 학생(희망 조합)`을 넣습니다.
4. **③ 배정하고 손보기** — 아래 막대의 `배정 실행`을 누르면 반별 인원·남녀·태그·힘든 점수(★) 균형과
   분리 그룹·3년 연속 같은 반 금지를 지키는 배정안이 나옵니다. 결과는 **모든 반이 한 줄로** 놓이고,
   반마다 `가반 18명 (남9 여9) ★12`처럼 인원과 점수 합계만 보여 줍니다. 남학생은 연한 하늘색, 여학생은 연한 분홍 카드로
   나뉘어 그 사이에 구분선이 있고, 태그는 `특수6`, `학습2`, `생활1`처럼 한 줄 배지입니다. 반 카드 요약은 학생마다 `특수6`, `학습·생활3`처럼 태그 조합과 개인별 별 합계를 표시합니다.
   학생을 끌어다 옮겨 직접 맞출 수도 있고, 빠진 학생은 반 카드 아래 `+ 학생 추가`로 그 반에 바로 넣습니다.
   명단 표 위의 `전체 / 5-1 / 5-2 …` 탭으로 반별로 걸러 볼 수 있습니다.
5. **④ 엑셀로 받기** — 결과 탭의 `엑셀 내려받기`(UTF-8 BOM CSV — `5학년 반, 번호, 이름, 6학년 반, 태그` 다섯 열)·`표로 복사`·`인쇄`로 가져다 씁니다.
   작업 전체는 `백업·관리` 안의 `작업 파일(.json)`로도 남겨 둘 수 있습니다.

## 저장

- 입력한 내용은 **암호로 보호된 Supabase 작업실**에 자동 저장됩니다(800ms 뒤). 같은 암호를 쓰는
  선생님과 명단을 함께 쓸 수 있고, 위쪽의 `[다른 선생님 수정 불러오기]`로 서버의 최신 내용을 받아옵니다.
- 화면을 열어 둔 동안에는 **10초마다 서버를 한 번 확인**해, 다른 선생님이 저장한 수정이 있으면 조용히 화면에 반영하고
  `다른 선생님의 수정 내용을 반영했습니다`라고 알려 줍니다. 입력 중이거나 저장 중일 때, 창(모달)이 떠 있을 때는 그 차례를 건너뜁니다.
- 다른 사람이 먼저 저장한 경우 `[최신 내용 불러오기]` / `[내 내용 덮어쓰기]` 중에서 고를 수 있습니다.
- 작업 중에 인터넷이 끊겨도 이미 연 화면과 내용은 이 브라우저(localStorage)에 남아 있고, 다시 연결되면 서버에 올라갑니다. 처음 들어갈 때는 암호 확인을 위해 서버 연결이 필요합니다.
- `[잠금]`을 누르면 화면이 곧바로 암호 화면으로 바뀌고, 잠긴 동안에는 뒤 화면이 보이지도 스크롤되지도 않습니다.

휴대폰(412px 등)에서는 표가 카드처럼 세로로 펼쳐져 가로로 넘치지 않습니다.

## 참고

- 무료 GitHub Pages는 public 저장소가 필요합니다. 이 저장소에는 **학생 명단이 들어 있지 않습니다** —
  명단은 암호로 잠긴 서버 저장소에만 있습니다.
- 배정 계산은 브라우저 안에서만 이루어집니다.

## 태그와 그룹 선택

- 태그 설정에는 이름·학생 인원수·삭제만 있습니다. 기본 점수와 반당 최대 인원 입력은 없습니다.
- 태그를 켜면 개인별 ★1로 시작합니다. 학생 명단과 결과의 학생 추가·수정 창에서 ★1~★5를 고릅니다. 개인별 별 합계는 최대 5점이며, 태그가 없으면 0점입니다. 반별 개인 점수 합계는 배정 알고리즘에서 균등 배분합니다.
- 특수학생은 새 반 구성에서 `통합학급`으로 체크한 반에만 배정합니다. 특수학생이 있으면 한 반 이상 체크해야 합니다.
- 분리 그룹은 2명 이상을 인원 제한 없이 추가할 수 있고 모든 구성원이 서로 다른 반이 되도록 배정합니다. 반 수보다 큰 그룹 등 불가능한 조건은 결과에서 경고합니다. 기존 2명 `pairs` 자료도 그대로 읽습니다.
- 분리 그룹과 희망 조합은 카드로 표시합니다. 학생 선택 팝업의 이름·반 검색과 왼쪽 반 목록을 사용하면 `5-1 김민준 (3번)`처럼 동명이인을 구분할 수 있습니다. 이름만 붙여넣는 일괄 입력은 제공하지 않습니다.
- 결과는 `남녀·가나다순`과 `5학년 반·번호순`으로 전환할 수 있습니다. 모든 반의 명단 시작 높이를 맞추며 성별 배경색과 태그별 파스텔 색상을 유지합니다.
- 구버전 저장 자료의 태그 기본 점수와 배수는 처음 읽을 때 개인별 별 수로 변환하고, 5점 상한을 적용합니다.
- 결과 카드의 학생 이름을 누르면 학생 수정 창을 엽니다. 창을 취소하면 기존 학생 정보와 배정 결과를 유지합니다.
- 점검 경고는 분리 그룹, 3년 연속 같은 반, 특수학생의 통합학급 미지정, 반드시 이 반, 반별 목표 인원 위반만 집계합니다. 남녀·일반 태그·별 총점·평균 편차는 배정에 참고하며 경고로 집계하지 않습니다.
- 경고가 있으면 결과 상단에 모든 사유와 해당 학생·반 이름을 펼쳐 표시합니다.

## 검증

```sh
node --test banbaejeong/tests/core.test.cjs
python -m http.server 4173
# 다른 터미널에서 실행 (Playwright 및 Chromium 필요)
node banbaejeong/tests/browser.cjs
```

브라우저 검사는 실제 Chromium에서 가상 Supabase 응답을 사용합니다. 암호 확인·저장·불러오기·10초 폴링 설정, 학생 선택, 6명 분리, 결과 정렬·요약·색상·반응형 화면, 5점 입력 제한과 주요 제약 경고의 상세 표시를 검증하며 실제 서버 명단을 변경하지 않습니다.
`BBJ_URL`과 `CHROMIUM_PATH` 환경 변수로 주소와 Chromium 경로를 바꿀 수 있습니다.

## 다음 학년도 학급 구성의 인원 계산

- 남 또는 여를 입력하면 목표 인원은 즉시 남+여로 바뀝니다. 목표 인원을 입력하면 기존 남녀 비율로 다시 나누며, 기존 인원이 0이면 반반으로 나눕니다.
- `통합학급은 N명 적게`는 **총원에 한 번** 적용합니다. 총원을 정한 다음 그 안에서 명단의 실제 남녀 합계에 맞춰 배분합니다. 전체 남녀 수가 같으면 각 반의 남녀 차이는 최대 1명입니다. 전체 성비가 다르면 실제 성비를 따릅니다.
- 예를 들어 108명(남54·여54), 6개 반, 통합학급 2개, 2명 감원은 통합학급 17·17명, 일반 반 19·19·18·18명으로 계산합니다. 총원108·남54·여54를 모두 정확히 유지합니다.
- 통합학급 체크, 감원 수, 반 개수를 바꾸면 즉시 자동 계산합니다. `학생 수에 맞춰 목표 인원 채우기`로 다시 맞출 수도 있습니다.
- 수동 수정 후 전체 총원이나 남녀 합계가 실제 명단과 다르면 차이를 안내하고 배정을 중단합니다. 고정 반 학생이 해당 반의 총원·남녀 목표를 넘는 경우도 배정 전에 안내합니다.
- 목표가 유효하면 자동 배정은 반별 총원·남녀 인원을 정확히 유지하면서 분리·통합학급·희망 조합·별 점수 배분을 개선합니다. 수동으로 학생을 옮겨 목표를 벗어나는 경우에는 기존 점검 경고를 표시합니다.
