# 반배정 도우미

4·5학년 반과 이름·성별·태그를 넣으면 6학년 반 편성을 고르게 짜 주는 도구입니다.
파일 하나(`index.html`)로 동작하는 웹앱이며, GitHub Pages에서 열립니다.

## 화면은 1→2→3→4 단계입니다

위쪽 길잡이(① 명단 올리기 · ② 반·조건 정하기 · ③ 배정하고 손보기 · ④ 엑셀로 받기)가
지금 어느 단계인지 보여 주고, 오른쪽 배지는 `실제 명단 108명` / `연습용 가상 명단 108명`처럼
지금 다루는 명단이 무엇인지 알려 줍니다.

1. 주소를 열면 **암호 입력 화면**만 보입니다. 암호가 맞고 서버에 연결되면 그때 서버에 저장된 최신 내용을 불러오며 화면이 열립니다.
2. **① 명단 올리기** — `명단 파일 올리기(.xlsx·CSV)`·`엑셀에서 붙여넣기`·`빈 양식 내려받기`로 명단을 넣습니다.
   명단 표에는 **번호(출석번호)** 칸이 있어 파일·붙여넣기의 `번호`·`출석번호`·`학번` 열을 그대로 읽습니다.
   연습은 `연습용 명단으로 해보기`(가상 108명)로 먼저 해 볼 수 있습니다.
3. **② 반·조건 정하기** — `새 반 구성`에서 반 개수와 목표 인원을 맞추고 `학생 수에 맞춰 목표 인원 채우기`를 누릅니다.
   새 반 이름은 기본이 **가반·나반·다반·라반·마반·바반**이고(반을 늘리면 사반·아반·자반·차반), 표에서 직접 고쳐도 됩니다.
   `통합학급` 체크는 통합학급 학생을 그 반에만 두거나 목표 인원을 몇 명 적게 잡을 때 씁니다.
   `태그와 힘든 점수(★)`(기본 태그: 학습·생활), `같이 두면 안 되는 학생(분리 짝)`, 필요하면 `같은 반이 되면 좋은 학생(희망 조합)`을 넣습니다.
4. **③ 배정하고 손보기** — 아래 막대의 `배정 실행`을 누르면 반별 인원·남녀·태그·힘든 점수(★) 균형과
   분리 짝·3년 연속 같은 반 금지를 지키는 배정안이 나옵니다. 결과는 **모든 반이 한 줄로** 놓이고,
   반마다 `가반 18명 (남9 여9) ★12`처럼 인원과 점수 합계만 보여 줍니다. 남학생은 연한 하늘색, 여학생은 연한 분홍 카드로
   나뉘어 그 사이에 구분선이 있고, 이름 옆 `☆3`은 그 학생의 힘든 점수, 태그는 `태그명 / ★개수` 두 줄 칩입니다.
   학생을 끌어다 옮겨 직접 맞출 수도 있고, 빠진 학생은 반 카드 아래 `+ 학생 추가`로 그 반에 바로 넣습니다.
   명단 표 위의 `전체 / 5-1 / 5-2 …` 탭으로 반별로 걸러 볼 수 있습니다.
5. **④ 엑셀로 받기** — 결과 탭의 `엑셀 내려받기`(UTF-8 BOM CSV — `5학년 반, 번호, 이름, 6학년 반, 태그` 다섯 열)·`표로 복사`·`인쇄`로 가져다 씁니다.
   작업 전체는 `백업·관리` 안의 `작업 파일(.json)`로도 남겨 둘 수 있습니다.

## 저장

- 입력한 내용은 **암호로 보호된 Supabase 작업실**에 자동 저장됩니다(800ms 뒤). 같은 암호를 쓰는
  선생님과 명단을 함께 쓸 수 있고, 위쪽의 `[다른 선생님 수정 불러오기]`로 서버의 최신 내용을 받아옵니다.
- 화면을 열어 둔 동안에는 **10초마다 서버를 한 번 확인**해, 다른 선생님이 저장한 수정이 있으면 조용히 화면에 반영하고
  `다른 선생님의 수정 내용을 반영했습니다`라고 알려 줍니다. 입력 중이거나 저장 중일 때, 창(모달)이 떠 있을 때는 그 차례를 건너뜁니다.
- 다른 사람이 먼저 저장한 경우 `[최신 내용 불러오기]` / `[내 내용 덮어쓰기]` 중에서 고를 수 있습니다.
- 작업 중에 인터넷이 끊겨도 이미 연 화면과 내용은 이 브라우저(localStorage)에 남아 있고, 다시 연결되면 서버에 올라갑니다. 처음 들어갈 때는 암호 확인을 위해 서버 연결이 필요합니다.
- `[잠금]`을 누르면 화면이 곧바로 암호 화면으로 바뀌고, 잠긴 동안에는 뒤 화면이 보이지도 스크롤되지도 않습니다.

## 좁은 화면

휴대폰(412px 등)에서는 표가 카드처럼 세로로 펼쳐져 가로로 넘치지 않습니다.

## 참고

- 무료 GitHub Pages는 public 저장소가 필요합니다. 이 저장소에는 **학생 명단이 들어 있지 않습니다** —
  명단은 암호로 잠긴 서버 저장소에만 있습니다.
- 배정 계산은 브라우저 안에서만 이루어집니다.
