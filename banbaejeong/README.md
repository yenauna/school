# 반배정 도우미

4·5학년 반, 이름·번호·성별·태그를 입력해 다음 학년도 반을 편성하는 단일 HTML 앱입니다.
Supabase 공유 저장, 암호 확인, 결과 탭 1초 실시간 갱신과 기존 JSON 작업 파일을 지원합니다.

## 화면 순서

첫 번째 `명단·조건` 탭은 다음 순서입니다.

1. **학생 명단** — 파일 올리기, 엑셀 붙여넣기, 학생 한 명 추가, 빈 양식, 연습용 명단, 전체 지우기를 첫 줄에서 사용합니다. 연습용 이름에는 성이 다르고 이름만 같은 경우를 서로 겹치지 않는 5쌍만 넣습니다. 둘째 줄에서는 태그를 추가·삭제합니다. 기본 태그는 `특수·학습·생활·학부모`이고 인원수 표나 별도의 태그 설정 카드는 없습니다. 그 아래 반별 탭·검색창·학생 표가 있습니다.
2. **조건 정하기** — 필수 분리 조합, 필수 희망 조합, 추천 희망 조합, 전출예정을 설정합니다. 모두 이름·반 검색 및 반/학생 좌우 목록이 있는 학생 선택 팝업을 사용합니다.
3. **다음 학년도 학급 구성** — 반별 통합학급 여부, 목표 총원과 감원 수를 설정합니다.
4. **백업·관리** — 접이식 패널에서 JSON 작업 파일을 저장·불러옵니다.

상단 단계 길잡이는 없으며 탭 옆에 연습용/실제 명단 인원 상태 배지만 표시합니다.

## 배정 조건

- **필수 분리 조합**: 한 그룹에 두 명 이상을 넣으며 모두 서로 다른 반에 배정합니다. 예전 2명 `pairs` 자료도 그대로 읽습니다.
- **필수 희망 조합**: 쌍둥이 등 같은 반에 넣어야 할 학생들입니다. 겹친 그룹도 연결해 하나의 배정 단위로 다룹니다. 나뉘면 학생·반 이름을 포함해 경고합니다. 같은 반 희망과 기존 3년 연속 규칙이 서로 충돌하면 필수 희망을 유지하고 3년 연속 위반을 경고합니다.
- **추천 희망 조합**: 기존 `wishGroups` 자료입니다. 가능하면 같은 반에 넣고, 나뉘면 참고로만 표시합니다.
- **전출예정**: 그룹이 아닌 학생별 상태입니다. 배정과 목표 인원에는 포함하고, 별 점수·반별 점수 합계·학생 기준 태그 요약에서는 제외합니다. 기존 개인 별 수는 보관하며, 전출예정을 해제하면 다시 사용합니다. 학생끼리 반마다 분산하도록 계산하고 이름 옆에 표시합니다.
- 성과 이름이 완전히 같은 학생은 자동으로 분리합니다. 성만 다르고 이름이 같은 학생은 강제 분리하지 않습니다. 조건 카드 맨 아래에서 `[필수] 동명이인`과 `[권장] 성 제외 이름 같음`을 그룹별로 한 번만 안내합니다. 해당 그룹이 없으면 `없음`을 표시합니다.
- 특수학생은 통합학급으로 체크한 반에 배정하고, 반당 최대 한 명입니다. 학급 구성 안내 옆에는 현재 명단에서 '특수' 태그가 붙은 학생 수를 표시하고 명단·태그 수정 시 갱신합니다. 체크하지 않은 반 또는 한 반에 두 명 이상이면 즉시 경고합니다.
- 분리·같은 반·고정 반·목표 정원 등이 서로 충돌해 모두 만족시킬 수 없으면 결과에 구체적인 위반을 표시합니다.

새 조건은 `requiredGroups`(학생 ID 배열의 배열)와 학생별 `transfer` 불리언으로 저장합니다. 이전 자료에 없는 필드는 빈 목록/거짓으로 처리합니다. 구버전 자료에는 새 기본 태그 `학부모`를 한 번 추가하며, 이후 사용자가 삭제하면 다시 만들지 않습니다.

## 별과 목표 인원

- 태그를 켜면 개인별 ★1로 시작합니다. 명단 표와 결과의 학생 추가·수정 창에서 최대 ★5까지 조절합니다. 개인별 별 합계는 최대 5점이고 태그가 없으면 0점입니다.
- 학급 구성 표에는 반 이름·통합학급·목표 인원(총원)만 있습니다. 남녀 목표 입력은 없고, 배정에서 실제 명단 성비에 맞춰 최대한 균등하게 나눕니다. 이전 파일의 남녀 값은 읽되 새 배정의 제약으로 사용하지 않습니다.
- `통합학급은 N명 적게`는 총원에 한 번 적용합니다. 총원을 정한 다음 그 안에서 실제 남녀 합계에 맞춰 나눕니다. 전체 성비가 반반이면 각 반의 남녀 차이는 최대 한 명입니다.
- 108명(남54·여54), 6개 반, 통합학급 2개, 2명 감원은 통합학급 17·17명, 일반 반 19·19·18·18명으로 계산합니다.
- 통합학급 체크·감원 수·반 개수를 바꾸면 다시 계산합니다. 전체 목표 총원이 명단과 다르거나 고정 학생이 해당 반의 목표를 넘으면 배정 전에 안내합니다.
- 유효한 목표는 자동 배정에서 반별 총원을 정확히 유지합니다. 필수 조합·고정 반을 지키면서 남녀 성비를 최적화하므로 남녀 수는 반마다 달라질 수 있습니다. 남녀·일반 태그 쏠림이나 별 점수 편차는 균등화에 참고하며 경고로 집계하지 않습니다.

## 결과와 실행 취소

- 상단 점검은 `특수·동명이인·이름만 같음·3년 같은 반·필수 분리·필수 희망·추천 희망·별점·남녀수` 9개 알약을 고른 너비로 배치하고 오른쪽 실행 취소와 정렬합니다.
- 필수 위반은 빨간불과 알약 아래 짧은 미니 카드를 표시합니다. 권장 항목 4개는 노란불만 켜며 명단을 자동으로 펼치지 않습니다. 마우스 호버 또는 키보드 포커스 시 위쪽 말풍선에서 상세를 확인하고, 벗어나거나 Escape를 누르면 숨깁니다.
- 별점은 반별 평균에서 `최대(2점, 학생 한 명의 최대 별점, 평균의 25%)`보다 크게 벗어날 때 `가반 별점 높음/낮음`을 표시합니다. 전출예정은 별점 계산에서 제외하며 나눌 수 없는 학생 한 명의 점수는 허용합니다.
- 남녀수는 각 반의 실제 총원 × 명단의 전체 성비에 따른 기대 인원과 비교해 2명 이상 벗어나면 `가반 남자수 적음`, `나반 여자수 많음`처럼 표시합니다. 통합학급의 작은 총원 자체로는 노란불을 켜지 않습니다.
- 필수 희망 조합의 이름 바로 오른쪽에 조합별 같은 색 `♥`를 표시합니다. 겹친 조합은 하나로 연결해 같은 색을 사용하며 보기 전환·이동·저장 후에도 동일하게 표시합니다.

- 화면 폭은 `min(1760px, 96vw)`까지 사용해 일반 모니터에서 6개 반을 한 줄에 표시합니다.
- `남녀·가나다순`과 `5학년 반·번호순`으로 전환합니다. 성별 배경색, 개인별 한 줄 태그 배지, 태그별 파스텔 색상과 명단 시작선 정렬을 유지합니다.
- 기본 보기는 `전체 2줄`입니다. 정렬 옆의 `전체 1줄`은 한 열, `전체 2줄`은 두 열이며 남학생 뒤에 여학생을 항상 새 줄에서 시작합니다. `남자 1줄·여자 1줄`은 왼쪽 남학생·오른쪽 여학생을 세로로 표시합니다. 두 열 배치에서는 선택한 정렬 기준을 각 성별 목록 안에 적용합니다. 보기 전환은 배정·조건·실행 취소 기록을 변경하지 않습니다.
- 결과 화면은 ① 제목과 다시 배정·복사·인쇄·엑셀 버튼 ② 슬림한 정렬·배치 토글 ③ 신호등과 오른쪽 실행 취소 ④ 반별 명단 순서입니다. 결과 탭에서는 하단 고정 바를 숨기고 명단·조건 탭에서는 다시 표시합니다.
- 별도 경고 팝업·긴 목록은 없습니다. 미니 카드는 `가반 허봄 · 진은비`처럼 단어 위주로 표시하며 이동·추가·수정 후 즉시 갱신합니다. 특수학생 중복/통합학급 미지정 학생은 빨간 테두리, 총원이 목표와 다르면 반 카드 전체가 빨간 테두리가 됩니다. 반 머리에는 `목표18/현재19`처럼 짧게 표시합니다. 남녀 편차는 노란불 참고 항목입니다.
- 신호등 줄 오른쪽의 `↩ 실행 취소`는 이동·반 내 추가·수정을 최대 50단계 되돌립니다. 학생 목록·조건·반별 목표·다음 ID까지 복원합니다. 새 자동 배정이나 서버/작업 파일 불러오기 후에는 이전 편집 기록을 사용하지 않습니다.

## 저장과 호환

- `banbaejeong_load`/`banbaejeong_save` RPC와 암호 확인을 유지합니다. 명단·조건 탭은 자동 서버 저장·갱신 없이 편집합니다. 하단 `저장`은 최신 서버 자료와 기준 상태를 비교해 내가 바꾼 학생 필드·조건만 병합하고 revision 충돌 시 다시 병합합니다. 다른 반의 수정·추가를 보존하며, 동시 추가 학생의 ID 충돌도 재발급합니다. 브라우저와 연결된 작업 파일의 로컬 보관은 유지합니다.
- `다른 반 내역 업데이트`는 내 미저장 변경을 보존하면서 최신 다른 반 내용을 받아오며 서버에 쓰지 않습니다. 결과 탭이 보일 때만 1초마다 새 revision을 확인하고 입력·저장·모달 중에는 건너뜁니다. 60초 무조작이면 정지하고 포인터·터치·스크롤·키 입력으로 재개합니다. 결과 편집은 기존처럼 800ms 뒤 자동 저장합니다.
- 분리 조합의 `서로서로`는 전원 상호 분리, `한 명을`은 첫 학생과 나머지만 분리합니다. 기존 `pairs` 배열과 호환하며 모드는 `pairModes`의 `all`/`one`으로 저장합니다. 객체형 `{members, mode}` 입력도 정규화합니다.
- 결과 학생 이름 클릭 시 고정 반을 수정할 수 있고 핀은 한 줄 안의 작은 아이콘으로 표시합니다. 모바일 명단은 얇은 행과 수정 모달을 사용합니다.
- 잠금 시 뒤 화면을 가리고 스크롤을 막습니다. 암호는 세션에만 보관합니다.
- 예전 태그 이름·기본 점수·배수·2명 분리 자료·추천 희망 조합·번호 없는 파일과 JSON 백업을 읽습니다. 저장소에는 실제 학생 명단이 없습니다.

## 검증

```sh
node --test banbaejeong/tests/core.test.cjs
python -m http.server 4173
# 다른 터미널 (Playwright와 Chromium 필요)
node banbaejeong/tests/browser.cjs
```

`BBJ_URL`과 `CHROMIUM_PATH`로 주소·브라우저 경로를 바꿀 수 있습니다. 브라우저 검사는 실제 Chromium에서 가상 Supabase 응답을 사용하므로 실제 서버 명단을 변경하지 않습니다. 신규 배치·태그·필수/추천 조합·동명이인·전출예정·실제 드래그·즉시 경고·여러 단계 실행 취소·정확한 인원 목표·반응형 화면과 저장/불러오기를 검증합니다.

동시 편집·실시간 갱신·모바일 회귀 검사: `BBJ_URL=http://127.0.0.1:4185/banbaejeong/ node banbaejeong/tests/collaboration.cjs` (격리된 가상 Supabase 사용).
