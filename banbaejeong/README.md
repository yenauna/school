# 반배정 도우미

4·5학년 반과 이름·성별·태그를 넣으면 6학년 반 편성을 고르게 짜 주는 도구입니다.
파일 하나(`index.html`)로 동작하는 웹앱이며, GitHub Pages에서 열립니다.

## 화면은 1→2→3→4 단계입니다

위쪽 길잡이(① 명단 올리기 · ② 반·조건 정하기 · ③ 배정하고 손보기 · ④ 엑셀로 받기)가
지금 어느 단계인지 보여 주고, 오른쪽 배지는 `실제 명단 108명` / `연습용 가상 명단 108명`처럼
지금 다루는 명단이 무엇인지 알려 줍니다.

1. 주소를 열면 **암호 입력 화면**이 나옵니다. 학교에서 함께 쓰는 암호를 넣으면 서버에 저장된 최신 내용을 불러옵니다.
2. **① 명단 올리기** — `명단 파일 올리기(.xlsx·CSV)`·`엑셀에서 붙여넣기`·`빈 양식 내려받기`로 명단을 넣습니다.
   연습은 `연습용 명단으로 해보기`(가상 108명)로 먼저 해 볼 수 있습니다.
3. **② 반·조건 정하기** — `새 반 구성`에서 반 개수와 목표 인원을 맞추고 `학생 수에 맞춰 목표 인원 채우기`를 누릅니다.
   `태그와 힘든 점수(★)`, `같이 두면 안 되는 학생(분리 짝)`, 필요하면 `같은 반이 되면 좋은 학생(희망 조합)`을 넣습니다.
4. **③ 배정하고 손보기** — 아래 막대의 `배정 실행`을 누르면 반별 인원·남녀·태그·힘든 점수(★) 균형과
   분리 짝·3년 연속 같은 반 금지를 지키는 배정안이 나옵니다. 학생을 끌어다 옮겨 직접 맞출 수도 있습니다.
   명단 표 위의 `전체 / 5-1 / 5-2 …` 탭으로 반별로 걸러 볼 수 있습니다.
5. **④ 엑셀로 받기** — 결과 탭의 `CSV 내려받기`·`표로 복사`·`인쇄`로 가져다 씁니다.
   작업 전체는 `백업·관리` 안의 `작업 파일(.json)`로도 남겨 둘 수 있습니다.

## 저장

- 입력한 내용은 **암호로 보호된 Supabase 작업실**에 자동 저장됩니다(800ms 뒤). 같은 암호를 쓰는
  선생님과 명단을 함께 쓸 수 있고, 위쪽의 `[다른 선생님 수정 불러오기]`로 서버의 최신 내용을 받아옵니다.
- 다른 사람이 먼저 저장한 경우 `[최신 내용 불러오기]` / `[내 내용 덮어쓰기]` 중에서 고를 수 있습니다.
- 인터넷이 끊겨도 이 브라우저(localStorage)에 저장되어 이어서 작업할 수 있고, 다시 연결되면 서버에 올라갑니다.
- `[잠금]`을 누르면 다시 암호 화면으로 돌아갑니다.

## 좁은 화면

휴대폰(412px 등)에서는 표가 카드처럼 세로로 펼쳐져 가로로 넘치지 않습니다.

## 참고

- 무료 GitHub Pages는 public 저장소가 필요합니다. 이 저장소에는 **학생 명단이 들어 있지 않습니다** —
  명단은 암호로 잠긴 서버 저장소에만 있습니다.
- 배정 계산은 브라우저 안에서만 이루어집니다.
